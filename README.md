# 🍔 FoodieHub - Online Food Ordering Website

FoodieHub is a simple and responsive online food ordering website developed using **HTML, CSS, and JavaScript**.

## ✨ Features
- View food items with images and prices
- Search food items
- Filter food by categories
- Add and remove items from cart
- Update cart quantity
- Calculate subtotal, delivery fee, and total amount
- Save cart data using LocalStorage
- Checkout form
- Save order history using LocalStorage

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage

## 🚀 How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
